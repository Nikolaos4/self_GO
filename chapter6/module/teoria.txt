Модуль в языке Go представляет коллекцию пакетов, который имеет встроенное версионирование и который можно опубликовать для использования в других проектах. 

Файлы go.mod и go.sum
    1. go.mod: Этот файл объявляет путь к модулю, версию Go, используемую в проекте, и список всех зависимостей с их минимальными требуемыми версиями.
    2. go.sum: Содержит криптографические хеши содержимого всех зависимостей. Это обеспечивает безопасность и воспроизводимость, гарантируя, что загруженные модули не были подделаны.

Основные операции с модулями:
    1. Инициализация модуля
       Чтобы превратить проект (каталог) в модуль, в корневом каталоге проекта надо выполнить команду: go mod init [имя_модуля]
    
    2. Добавление зависимостей
       При импорте новых пакетов в код программы и запуске команд go build или go test, Go автоматически добавит все необходимые 
       зависимости в файл go.mod. Но также можно добавить зависимость вручную с помощью команды: go get [путь_к_пакету]@[версия]
    
    3. Удаление неиспользуемых зависимостей. Со временем в вашем go.mod могут накопиться неиспользуемые зависимости. Их можно удалить командой:
       go mod tidy. Эта команда также добавит недостающие зависимости.

    4. Обновление зависимостей. Для обновления всех зависимостей до последних минорных или патч-версий (сохраняя мажорную версию), 
       применяется команда: go get -u
       Для обновления до конкретной версии: go get [путь_к_пакету]@latest



Создание модуля: 
    1. Создали папку, где будет расположен модуль и перешли в нее. С помощью команды go mod init имя_модуля создаем модуль.
       После выполнения этой команды в папке появится файл go.mod - это файл конфигурации проекта/модуля на Go. По умолчанию он будет иметь содержимое типа следующего:
       Первая строка с директивой module определяет путь к модулю. Вторая строка определяет используемую для модуля версию go.
       Кроме пути к модулю и версии go этот файл может содержать и другую информацию, например, информацию об используемых зависимостях и т.д.

    2. Далее в этой же папке создаем main.go. для запуска проекта пишем в терминале команду go run main.go. Но мы можем сократтить команду, поставив .: go run .
       То же самое мы можем сделать при построении из модуля: go build .


Если наш проект будет использовать Git и располагаться где-то во репозитории, то обычно в качестве имени модуля используется URL репозитория. Например:
go mod init github.com/your-username/your-project
