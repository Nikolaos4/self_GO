Горутины (goroutine) представляют параллельные операции, которые могут выполняться независимо от функции, в которой они запущены. 
Главная особенность горутин состоит в том, что они могут выполняться параллельно. То есть на многоядерных архитектурах есть возможность 
выполнять отдельные горутины на отдельных ядрах процессора, тем самым горутины будут выполняться паралелльно, и программа завершится быстрее.

Когда мы запускаем программу на Go, мы уже работаем как минимум с одной горутиной, которая представлена функцией main. Эта функция 
последовательно выполняет все инструкции, которые определены внутри нее. Как только компилятор достигает конца функции main, он завершает 
все созданные горутины.

Для определения горутин применяется оператор go, который ставится перед вызовом функции: go вызов_функции

Если в программе есть горутина, то она может не успеть выполнить свою работу до завершения основной функции main()
Горутины могут представлятьтакже вызов анонимных функций: файл anonim.go. Встроенный пакет time в Go определяет функциональность, 
которая может помочь при работе с потоками. В частности, этот пакет определяет функцию time.Sleep(), которая приостанавливает выполнение 
горутины на определенное время (в миллисекундах).

В языке Go мы можем зафиксировать количество ядер процессора для запуска горутин в программе. Существуют различные способы запуска горутин 
на нескольких ядрах системы. Go предоставляет переменную окружения GOMAXPROCS, которая определяет количество ядер, используемых в программе. 
Эта переменная берет на себя управление во время выполнения в программе Go. Значением по умолчанию этой переменной является количество ядер, 
доступных в системе. Система определяет при запуске в соответствии с запущенной операционной системой.
