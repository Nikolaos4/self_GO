Каналы (channels) представляют инструменты коммуникации между горутинами. В языке Go канал имеет определенный тип, то есть тип значений, 
которые он может передавать из одной горутины в другую. Для определения канала применяется ключевое слово chan. После слова chan указывается 
тип данных, который будет передаваться с помощью канала. Например: var intCh chan int.
При простом определении переменной канала она имеет значение nil, то есть по сути канал неинициализирован.

Для инициализации канала применяется функция make(). Объявление канала с помощью make() резервирует место в хранилище, инициализирует 
память и создает базовый заголовок определенного типа: var intCh chan int = make(chan int)

Для передачи в канал данных используется <-: intch <- 5
Для извлечения из канала данных: val := <- intch

Как правило, отправителем данных является одна горутина, а получателем - другая горутина. В зависимости от определения емкости канала он может быть буферизированным или небуферизированным.
Для небуферизированного канала используется конструкция: var intCh chan int = make(chan int). Если канал пустой, то горутина-получатель блокируется, пока в канале не окажутся данные. Когда горутина-отправитель посылает данные, горутина-получатель получает эти данные и возобновляет работу.

Горутина-отправитель может отправлять данные только в пустой канал. Горутина-отправитель блокируется до тех пор, пока данные из канала 
не будут получены. 

Общий ход выполнения программы в файле anonim.go выглядит следующим образом:
-Запускается функция main. Она создает канал intCh и запускает горутину в виде анонимной функции.
-Функция main продолжает выполняться и блокируется на строке fmt.Println(<-intCh), пока не будут получены данные.
-Параллельно выполняется запущенная горутина в виде анонимной функции. В конце своего выполнения она отправляет даные через канал: intCh <- 5. Горутина блокируется, пока функция main не получит данные.
-Функция main получает отправленные данные, деблокируется и продолжает свою работу.

Если же мы работаем с обычными функциями, то объекты каналов надо передавать через параметры - файл external.go

Буферизированные каналы также создаются с помощью функции make(), только в качестве второго аргумента в функцию передается емкость 
канала. Если канал пуст, то получатель ждет, пока в канале появится хотя бы один элемент.

При отправке данных горутина-отправитель ожидает, пока в канале не освободится место для еще одного элемента и отправляет элемент, 
только тогда, когда в канале освобождается для него место.

С помощью встроенных функций cap() и len() можно получить соответственно емкость и количество элементов в канале

Если необходимо определить функцию, которая возвращает канал, то все операции чтения-записи в канал следует вынести в отдельную горутину: файл output_channel


Каналы бывают двухнаправленные и однонаправленные
Канал, если он создан командой make(chan int), по умолчанию двухнаправленный, то есть он может как принимать данные, так и отправлять.
Создание канала на отправку: make(chan <- int)
Создание канала на получение: make(<- chan int)
