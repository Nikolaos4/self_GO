select в Go используется для ожидания нескольких операций канала одновременно. Оператор select похож на switch, который работает с 
несколькими выражениями case. В операторе select операторы case применяются к операциям отправки/получения данных канала. Select 
выбирает определенный оператор case для выполнения операции. Важно: select работает только с одной операцией(та, которая будет получен первой)
