Мьютексы позволяют разграничить доступ к некоторым общим ресурсам, гарантируя, что только одна горутина имеет к ним доступ в определенный
момент времени. И пока одна горутина не освободит общий ресурс, другая горутина не может с ним работать.

На уровне кода мьютекс представляет тип sync.Mutex, который определен в пакете sync. Для блокирования доступа к общему разделяемому 
ресурсу у мьютекса вызывается метод Lock(), а для разблокировки доступа - метод Unlock().

Горутина может только считывать данные, либо только изменять их. При выполнении операции записи совместное использование данных несколькими 
горутинами не допускается, тогда как при операции чтения несколько горутин могут считывать одни и те же данные без каких-либо проблем. Go 
предоставляет специальный мьютекс для чтения/записи - структуру sync.RWMutex, которая содержит различные поля для отслеживания доступа к памяти 
несколькими потоками. sync.RWMutex реализует несколько методов для блокировки/разблокировки:

- RLock(): используется для получения блокировки на чтение. Несколько читателей могут получить эту блокировку в одной программе. Блокировка на чтение не привязан к определенному потоку.

- RUnlock(): освобождает полученную одну блокировку на чтение.

- Lock(): блокирует мьютекс для записи. Доступен только для одного потока за раз. Если другой поток получает блокировку для целей чтения/записи, Lock блокируется до тех пор, пока блокировка не станет доступной для получения.

- Unlock(): снимает блокировку на запись. При выполнении Unlock без получения блокировки мы получим ошибку во время выполнения.
