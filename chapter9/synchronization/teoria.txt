Для упрощения синхронизации между горутинами в Go имеется пакет sync, который предоставляет ряд возможностей, в частности, структуру 
sync.WaitGroup. Этот тип позволяет определить группу горутин, которые должны выполняться вместе как одна группа. И можно установить 
блокировку, которая приостановит выполнение функции, пока не завершит выполнение вся группа горутин.

WaitGroup — это структура, которая содержит счетчик количества горутин, завершения которых нам нужно дождаться. Он используется для 
ожидания завершения всех горутин. Для отслеживания всех горутин, которые вызываются в программе, WaitGroup предоставляет ряд методов:
-Add: сообщает, сколько горутин нужно дождаться.
-Done: вызывается при завершении горутины, чтобы указать, что ее выполнение завершено.
-Wait: используется основной горутиной, пока счетчик не станет равным нулю. Когда все горутины завершаются и счетчик становится равным нулю, функция Wait() возвращается и продолжает дальнейшее выполнение.
