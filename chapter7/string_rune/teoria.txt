Строки являются одним из важных типов данных языке Go и сильно отличаются от строк в других языков: в других языках программирования
строка нередко определяется как массив символов, но в Go строка — это срез байтов. По умолчанию строки кодируются в UTF-8 в языке Go. 

Строки всегда определяются двойными кавычками, в то время как отдельные символы  с пмощью одинарных

Для вычисления длины строки применятеся функция len(), которая возвращает общее количество байт, занимаемых каждым из символов

rune представляет встроенный тип данных в языке Go. В реальности это псевдоним для int32, поскольку Unicode UTF-8 кодирует символ в
уникальное число или кодовую точку. Руна и представляет эти кодовые точки Unicode в Go. Она не связана с количеством байтов, которые 
занимает символ. Для определения одной руны можно использовать символ или его числовой код:

В языке Go мы не можем изменить значение строки после того, как она определена. Можно сказать, что строка — это срез байтов, 
доступный только для чтения. Мы можем получить доступ к любому символу строки, но при изменении ее значения или увеличении ее длины 
компилятор выдаст ошибку (cannot assign to str[1])

Есть определенные случаи, когда нам нужно изменить значение строк. И в этом случае помогают руны. Мы можем преобразовать строку в 
тип руны, изменить значение по мере необходимости, а затем назначить руну строке:
    str := "Hello"
 
    fmt.Println(str)     // Hello
 
    rune_str := []rune(str)  // преобразуем строку в руны
    rune_str[1] = 'a'       // изменяем руны
 
    str = string(rune_str)  // преобразуем обратно руны в строку
